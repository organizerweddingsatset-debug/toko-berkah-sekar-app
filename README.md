# Toko Berkah Sekar - Android & Web App

A modern, responsive e-commerce mobile & web application for **Toko Berkah Sekar** built with React, Vite, Tailwind/Modern CSS, and Capacitor.

## Features
- 🌸 Catalog & Flower Bouquet Customizer
- 🛒 Cart & Checkout with QRIS & Payment Simulation
- 📦 Order Tracking & History
- 📱 Native Android APK support via Capacitor
- ⚡ Automated GitHub Actions APK Builder

## Building the Android APK
The Android APK is automatically built by GitHub Actions whenever changes are pushed to `main`. Download the APK from the GitHub Actions Artifacts tab.
